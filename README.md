# Elite Auto Gallery

A responsive luxury automotive marketing website built with Vue 3, TypeScript and Vite. The visual direction uses a charcoal-black canvas, champagne-gold accents and editorial typography.

## Features
- Responsive navigation and hero landing section
- Curated vehicle collection with category filters
- Vehicle cards with sample specifications and USD pricing
- Brand experience, trust points and contact sections
- Email enquiry links
- Responsive mobile layout

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Before publishing
1. Replace the sample vehicle inventory, images, prices and descriptions with authorized dealership content.
2. Replace `enquiries@eliteautogallery.example` with a real monitored business email.
3. Add the dealership's real address, phone number, legal details and social links.
4. Confirm image licensing and use images you own or are licensed to publish.
5. Connect a real enquiry form/CRM if you need to store customer leads.

## Deploy
Import this repository into Vercel. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`.

This is a frontend demonstration. It does not yet include an inventory backend, authentication, payments or a lead-management database.
